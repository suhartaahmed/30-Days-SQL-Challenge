# 30 Days SQL Challenge

A hands-on SQL practice project featuring 30 daily SQL solution files based on interview-style questions from DataLemur, LeetCode, and company-style problem sets.

The goal of this project was to strengthen practical SQL problem-solving skills, practice commonly used SQL techniques, and build confidence working with PostgreSQL.

## Project Overview

Throughout this challenge, I worked on SQL problems independently, wrote my own queries, and tested my solutions using PostgreSQL.

The solutions are organized into 30 daily SQL files, making it easier to review individual problems and revisit concepts.

## Tools & Technologies

- **PostgreSQL** — writing and testing SQL queries
- **SQL** — solving analytical and interview-style problems
- **GitHub** — version control and project documentation

## SQL Concepts Practiced

- Window Functions
- Common Table Expressions (CTEs)
- Joins
- Aggregate Functions
- Date Functions
- Subqueries

## Project Structure

The repository contains 30 daily SQL files, organized from Day 1 through Day 30.

Each file contains the SQL work associated with its respective practice session.

## Learning Approach

My approach throughout the challenge:

1. Select a SQL interview-style problem.
2. Understand the problem requirements.
3. Develop an independent SQL solution.
4. Execute and test the query in PostgreSQL.
5. Organize the solution into the corresponding daily SQL file.

## Project Objectives

- Improve SQL query-writing skills.
- Strengthen analytical problem-solving.
- Practice SQL concepts frequently used in Data Analyst interviews.
- Gain practical experience using PostgreSQL.
- Build a publicly accessible record of SQL practice and progress.
